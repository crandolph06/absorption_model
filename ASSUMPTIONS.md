# Assumptions

## RAP Assumptions
- Maximum of 1 single ship sortie can be counted toward RAP per month
- Pure RAP - i.e. no sims supplement for sorties

## Resource Assumptions
- PAA * UTE = sorties available
- Unlimited sims available

## Upgrade Assumptions
- If an upgrade is deferred, the student does not graduate until the end of the phase, even if only one event was left.
